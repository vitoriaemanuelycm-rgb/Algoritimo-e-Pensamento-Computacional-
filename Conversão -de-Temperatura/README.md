## Conversor de Temperatura
O código feito em linguagem C é um conversor de temperatura com 6 opções de conversão, que são: de Kelvin para Celsius, Kelvin para Fahrenheit, Celsius para Kelvin, Celsius para Fahrenheit, Fahrenheit para Celsius e Fahrenheit para Kelvin.

As seis opções são mostradas na tela para o usuário através da função printf e lidas pelo scanf, onde se utiliza o switch como um seletor para direcionar a opção certa para fazer o cálculo. Se o case (que define se o valor que será comparado é igual à opção que o usuário digitou) for igual ao com o número digitado pelo usuário, ele executa fazendo o cálculo e mostrando o resultado.

No final do programa, foi utilizada uma função chamada default, que é um else só que em linguagem C, para caso o usuário  digite um número que não está entre as  opções — por exemplo 7 —, Asim o programa percebe  é executada uma mensagem de erro.
